# Signalman AI v0.10.5-alpha

## 更直观的服务商工作台

- 服务商、模型目录和切换前检查现在是更清晰的主入口；检查并切换的位置固定，不会在当前服务商变化时导致布局跳动。
- 访问密钥会以掩码显示，并提供显隐按钮；界面不会把已保存的密钥回传到页面。
- 每次准备切换时，应用会重新探测所选服务商；认证、接口、响应形态、计费和服务端异常会分别说明。只有无法证明安全写入时才会阻止。

## 新增性价比中心

- 在“实验室 > 性价比中心”用同一条极短固定测试比较不同服务商的实际人民币成本。
- 响应中明确返回费用时，测试额度会自动预填；未返回时可从服务商使用日志复制后保存。
- 排名只比较同一模型中的记录，不会读取平台账单、自动充值、切换服务商或改写 Codex 配置。

## 更新的使用说明

- README 现附带当前界面的脱敏截图：服务商配置、切换前检查、配置保护和性价比中心。
- 本版本仍为 GitHub alpha 日常渠道；Microsoft Store 是独立的低频稳定渠道，本次不提交 Store。

# Signalman AI v0.10.1-alpha

## 认证与配置安全

- 自定义 provider 的检查改为显示当前认证方式，不再错误要求 `config.toml` 中存在 `api_key`。
- 未声明认证方式时，切换仅更新 provider、模型和接口地址，不会改写 `auth.json`。
- 登录认证或环境变量认证尚未完成隔离运行时验证时，应用会停止自动切换，不会猜测或覆盖凭据。

## 恢复点与版本识别

- 未完成、损坏或旧格式的备份目录不再显示为可安全恢复的项目，也不会被静默删除。
- 新创建的自动恢复点最多保留 3 个，恢复前回退点保留 1 个；旧历史恢复点不自动清理。
- 手动恢复点最多保留 3 个；创建第 4 个前会明确确认替换最早的受管手动恢复点。
- 标题栏显示版本、渠道和构建提交短 SHA，便于区分稳定版、维护候选版和开发版。

## 已知边界

- 本版本仍为 alpha。切换后请在新的 Codex 会话中确认实际工作正常。
- Microsoft Store 保持独立的低频稳定渠道，本次 GitHub alpha 不会自动更新 Store。

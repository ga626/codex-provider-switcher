# Signalman AI v0.10.3-alpha

## 更可靠的通用中转站切换

- 每次确认切换前，应用都会针对将要写入的 config 与 auth 候选执行一次新的服务商探测。探测不通过会明确列为“使用风险”，由用户确认后仍可继续；只有无法证明写入安全时才会阻止操作。
- 对保存了应用访问密钥的普通 OpenAI-compatible 服务商，候选 `auth.json` 会同步使用同一密钥，并在 provider 配置中显式声明认证模式。这样“检查通过”与“实际写入”的认证合同保持一致。
- 切换事务覆盖 config 与认证目标；如果认证写入失败，应用会回写原配置。启动时发现未完成事务会从受保护恢复点恢复相应 provider/auth 字段，同时保留后来增加的未知认证字段。

## 模型目录和操作界面

- 模型目录现在识别常见的 `data[]`、`models[]` 和顶层数组响应。对于空目录、非 JSON 或登录页响应，会显示内容类型、最终地址和响应形状等不含密钥的诊断信息。
- 所有工作区都可使用“切换到所选服务商”，不再要求先回到“切换前检查”页面。
- 风险确认框的复选框恢复正常尺寸，并提供清晰的键盘焦点提示。

## 已知边界

- 本版本仍为 alpha。切换完成后请在新的 Codex 会话中执行一次最小真实请求；服务商的额度、账号权限、风控和完整工具协议由实际服务端决定。
- `wire_api = "responses"` 仅选择 Responses 协议，不等同于关闭 Responses Lite。GPT-5.6 的完整工具回路仍需要在实际新会话中单独确认。
- Microsoft Store 是独立的低频稳定渠道，本次 GitHub alpha 不会同步更新 Store。

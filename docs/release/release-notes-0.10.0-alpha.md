# Signalman AI 0.10.0-alpha 发布说明

## 这次更新

这是一轮面向朋友测试的配置保护升级。它不会承诺所有第三方服务商都可用；重点是让 Signalman 在不能证明安全时停止，而不是悄悄覆盖你的 Codex 设置。

## 用户能看到的变化

- 首次启动会只读创建“首次启动基线备份”，此后每天首次打开自动备份，也可以随时手动备份当前状态。
- 切换前先做服务商可用性测试，并生成十分钟有效的变更预览；确认时发现配置已被其他程序改动会拒绝写入。
- 恢复需要输入“恢复”二次确认；恢复只回退 Signalman 管理的 provider 字段，保留 MCP、插件、项目设置和认证文件中的其他内容。
- 配置保护、切换前检查、活动记录和服务商排序已拆分为独立工作区；服务商列表支持鼠标拖拽和键盘排序。

## 安全边界

- 备份使用当前 Windows 用户的 DPAPI 保护，并在使用前校验完整性；应用不会上传 provider、密钥或配置内容。
- 配置和认证文件不是跨文件原子写入。应用记录本地事务回执；异常或无法验证的状态会停止自动继续，不能替代在新 Codex 会话中的实际 canary。
- 此版本不更新 Microsoft Store；GitHub Release 安装包完成下载、安装、启动和 SHA256 验收后，才是可交付版本。

# Signalman AI v0.10.4-alpha

## 更稳定的服务商可用性测试

- Responses 可用性探针的总等待预算由 8 秒调整为有界的 15 秒，降低推理模型首次响应较慢或短暂上游抖动时出现假阴性的概率。
- 探针不会在超时后自动重复提交推理请求，避免服务端已经处理请求但响应未返回时产生重复计费。
- 本次调整适用于普通 OpenAI-compatible 服务商，不针对特定中转站；服务商余额、限流、认证和模型权限仍以实际 HTTP 响应为准。

## 已知边界

- 本版本仍为 alpha。网络中断或服务端持续无响应仍会显示为未确认，用户可重新运行测试。
- Microsoft Store 是独立的低频稳定渠道，本次 GitHub alpha 不会同步更新 Store。

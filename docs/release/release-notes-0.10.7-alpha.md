# Signalman AI v0.10.7-alpha

## 首次使用先准备环境

- 新安装用户不再直接落入空白工作台或切换前检查。首次打开会先显示独立的“准备连接环境”页面，说明本次操作范围，并要求用户选择要管理的 Codex 配置层。
- 该步骤会创建恢复点，只统一 Signalman 必需的服务商和 Responses 设置；项目、MCP、插件、hooks、历史和其他未知配置会保留。多个配置层不会被自动合并或猜测。
- 准备完成后才进入正常工作台和逐步使用说明，按“添加服务商、保存、刷新模型、运行测试、检查并切换”的顺序引导完成第一次切换。

## 服务商工作台与诊断

- 服务商页重组为左侧列表、中间配置和右侧固定检查栏。检查并切换、可用性测试、连接环境与完整检查结果不再随着选中的服务商或窗口尺寸改变位置。
- 默认模型支持输入搜索、展开和滚动选择；访问密钥默认显示为星号，眼睛按钮只在本机临时显示内容。
- 可用性测试会把连接、认证、限流、响应形态、模型目录与配置写入安全分开呈现，方便判断是服务商问题还是本机环境问题。
- 失败场景会出现“报告兼容问题”。预览只含版本、接口域名、模型和失败状态。在线维护者中继尚未配置时，用户只能导出这份脱敏内容，不会自动上传任何资料。

## 性价比与界面材料

- 性价比中心保留固定测试和同模型比较：一次测试即可生成记录，多次测试用于提升成本比较稳定性；样本、成本、官方对照、评分与删除记录的操作按统一布局展示。
- README、安装说明、排错指南、隐私政策、产品规格和五张无凭据示例截图已与当前界面同步。

本版本作为 GitHub alpha 日常渠道发布。Microsoft Store 继续是独立、低频的稳定渠道，本次不创建 Store 提交。

# Signalman AI v0.10.6-alpha

## 更稳定的桌面布局

- 顶部四个主导航采用统一的四等分布局。窗口收窄时文字会平滑淡出并保留图标入口，不会再出现导航位置突然跳变；当前工作区不会因尺寸变化而改变。
- 服务商、配置保护、活动记录和实验室共用统一的间距、字体层级、圆角和内容宽度规则。宽屏内容保持居中，最小桌面尺寸不退化为移动端布局。

## 更清楚的性价比排名

- 性价比中心的表头和数据行现在共用同一套列模板；排名、服务商、估算成本、官方对照、评分、样本和管理按钮按固定的对齐与间距排列。
- “估算成本”和“官方对照”具有相同的列宽策略，不再视觉粘连；980×700 的最小桌面窗口也不会出现横向滚动条。
- 固定测试模型、费用样本、官方对照和评分的现有计算规则不变；本次只让结果更容易阅读和比较。

## 更新的使用材料

- README 的服务商、切换前检查、配置保护和性价比中心截图已按当前界面重新生成。
- 所有截图使用无凭据的隔离 fixture，不包含真实服务商、访问密钥、账单、本机路径或 Codex 配置。

## 下载与渠道

本版本作为 GitHub alpha 日常渠道发布。Microsoft Store 继续是独立、低频的稳定渠道，本次不创建 Store 提交。

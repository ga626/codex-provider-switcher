# Signalman AI v0.10.8-alpha

## 更新与首次使用

- “检查更新”现在会显示检查时间、下载进度，以及网络、代理或签名失败的可操作提示。GitHub 需要代理的网络环境可使用 Windows 系统代理；检查失败不会伪装成已是最新版。
- 已完成首次准备的电脑在普通升级后不会重新进入准备页或强制重看初始化说明。新安装仍先创建恢复点并准备连接环境。

## 分章节使用说明

- 使用说明现分为六章：初始化配置、服务商、安全与恢复、活动记录、实验室、整体功能。
- 初始化会在首次准备完成后自动开始；其他章节可从状态栏或当前工作区标题旁的问号按需查看。
- 每章会定位到实际控件，支持上一步、稍后再说和本地进度续看；不读取或上传 Codex 配置、密钥或活动资料。

## 文档与发布材料

- README 已更新首次使用路径和章节说明。
- 发布材料替换为七张离线 fixture 截图，覆盖首次准备、服务商工作台、说明目录、安全恢复、活动记录、实验室和应用设置；不含真实服务商、密钥、本机路径或账单。

本版本通过 GitHub alpha 渠道发布。Microsoft Store 仍为独立、低频的稳定渠道，本次不创建 Store 提交。

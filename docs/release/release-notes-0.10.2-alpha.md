# Signalman AI v0.10.2-alpha

## 更清晰的应用设置

- 应用设置从工作区调整为顶栏入口，集中管理应用级偏好，不再干扰服务商、切换前检查和配置保护的日常操作。
- 设置分为“启动”“恢复保护”“更新”三组。开机启动仍默认关闭；首次基线会永久保留；自动保护和手动保存的保留数量可分别调整。
- 手动保存和安全恢复仍在“配置保护”中完成，避免同一操作出现在多个位置。

## 更新入口与渠道边界

- “检查更新”现位于“应用设置 > 更新”，集中显示当前版本、发布渠道和更新状态。
- GitHub 稳定安装版继续使用受签名保护的更新路径；Microsoft Store 安装版继续由 Store 管理更新。
- 本地预览和维护候选版不会检查或打开公开更新，避免测试环境误触发下载。

## 配置保护与切换提示

- 恢复中心按首次基线、自动保护和手动保存分组，便于区分每个恢复点的用途。
- 切换前检查将“安全写入阻止”和“使用风险可继续”分开显示；应用仍只写入确认归属的 provider 字段，不接管 MCP、插件、项目或其他 Codex 内容。

## 已知边界

- 本版本仍为 alpha。切换后请在新的 Codex 会话中确认实际工作正常。
- Microsoft Store 是独立的低频稳定渠道，本次 GitHub alpha 不会同步更新 Store。

# Signalman AI v0.10.13-alpha

## 初始化与配置安全

- 首次初始化按后端真实任务回执推进，所有任务完成后统一显示结果；失败、降级和需要处理的情况分别说明，无法安全完成时阻止进入工作台。
- 配置备份、恢复和切换事务覆盖模型目录、provider/auth 路由、写入后回读和进程中断恢复；历史恢复点按对应指纹版本兼容校验。
- 复用连接时会核对模型目录归属和有效性，发现旧目录指针或不完整备份会重新准备恢复点，避免继续使用旧配置。

## QA 与开发隔离

- 提供无凭据的首次启动模拟、边界场景、真实验证副本和 QA 控制台；模拟只预览状态，不冒充真实完成。
- 开发桌面板使用隔离运行目录，启动前按精确路径关闭旧开发板，不触碰稳定安装和真实 Codex 配置。
- 前后端、模型目录、恢复页面和首次启动说明同步更新，错误提示改为面向普通用户的原因与处理方式。

## 发布边界

- 本版本为 GitHub alpha 渠道发布；Microsoft Store 不随本版本更新。
- 安装包来自同一冻结提交的候选制品，并在隔离目录完成安装和启动检查。

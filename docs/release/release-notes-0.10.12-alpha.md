# Signalman AI v0.10.12-alpha

## 三种连接来源，各自走正确的配置流程

- 新增连接时先选择 ChatGPT 官方账号、厂商官方 API 或中转站，不再把 OAuth、官方密钥和中转密钥塞进同一张表单。
- ChatGPT 官方账号由 Signalman 发起 Codex 官方登录并显示等待与确认状态；邮箱、密码和授权确认始终只在 OpenAI 官方页面完成，Signalman 不读取或展示 token。
- 厂商官方 API 可预填 DeepSeek、OpenAI Platform、MiMo、Gemini 和 Grok 等常用官方接口；用户仍需使用对应厂商自己的 API Key 和额度。

## 模型目录更清楚，也不会无限拉长页面

- 默认模型目录在字段下方展开，模型列表在模块内部滚动，并支持按模型、厂商或能力搜索。
- 模型按“已验证、需确认、暂不可用”分组。已验证模型优先；能力未完整证明的模型会先说明风险；向量、音频或已知协议不兼容模型不会被当作 Codex 默认模型直接选择。

## 用实际返回能力判断未知服务商

- 可用性测试不再依赖域名或模型名称猜厂商。它先验证 Responses 完整流式生命周期，平台明确不接受流式时再检查非流式 Responses，Responses 路径明确不存在时才识别普通 Chat Completions。
- 结果区分“完整可用”“基本可用”“仅普通聊天”和“流式中断”。基本调用成功但流式没有得到证明时，切换前仍会要求确认长任务与实时输出风险。
- 只有尚未收到 HTTP 响应的连接失败才会新建连接重试一次；收到 HTTP 状态或流式事件后不会自动重发，避免同一个请求重复计费。
- 活动记录会保存脱敏的接口类型、流式状态、完成状态、响应头时间、首事件时间、总耗时和重试次数，不保存提示正文、完整响应或密钥。

## 全面整理工作台与费用说明

- 统一字体、字号、间距、图标、状态色和桌面响应式规则；首次准备改为从顶部逐项推进的信息流，活动记录优先显示结果、原因和下一步，安全恢复按工作内容、扩展能力和本机习惯说明保护范围。
- 实验室明确区分实测人民币成本、用户实际额度汇率和官方 API 人民币对照，额度单位支持美元额度、人民币余额和平台点数。
- 实验室固定成本测试仍等待完整响应与 usage，不会因为可用性测试已经收到响应头或首个流式事件而提前结束。

## 发布与安全边界

- Release CI 会把同一已验证 NSIS 候选安装到隔离目录，并检查桌面程序、本地后端和卸载程序都来自该候选。
- 切换和恢复仍只处理 Signalman 管理的服务商字段；MCP、插件、钩子、项目、桌面设置、记忆和本地历史不作为覆盖目标。
- GitHub alpha 安装包尚未购买 Windows Authenticode 签名；Windows SmartScreen、Smart App Control 或企业策略仍可能提示或阻止安装。

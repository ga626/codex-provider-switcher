# Signalman AI v0.10.9-alpha

## 恢复点兼容修复

- 修复较早版本创建的首次启动恢复点，在升级后可能被错误报告为“恢复点与记录的配置摘要不一致”的问题。该误报会阻止服务商切换，本版本已恢复兼容读取。
- 应用仍会先校验加密备份文件的完整性和当前 Windows 用户保护，再使用与该恢复点匹配的历史摘要格式验证；校验失败仍会停止切换或恢复，不会降低保护要求。
- 新建恢复点和切换/恢复回执会记录摘要版本，避免将来的校验规则增强影响已有资料。

## 用户资料与渠道

- 安装升级不会删除或重置已有服务商、恢复点、Codex 配置或认证资料。
- 本版本通过 GitHub alpha 渠道发布。Microsoft Store 仍为独立、低频的稳定渠道，本次不创建 Store 提交。

## 服务商配置与模型目录

- 填写服务商名称、接口地址和访问密钥后，可以在未保存的情况下直接刷新模型目录；预览请求只使用当前表单，不写入本机服务商目录、Codex 配置或认证文件。
- 默认模型下拉框支持展开、滚动和模糊搜索；选择模型只回填当前表单，仍需点击“保存更改”才会持久化。
- 服务商名称、接口地址、默认模型和访问密钥统一使用问号角标说明；接口说明提示填写 API 基地址，Codex 连接失败时可尝试补上 `/v1`。

## 使用说明与反馈

- 首次准备完成后进入初始化配置说明；完整使用说明拆分为初始化配置、服务商、安全与恢复、活动记录、实验室和整体功能六个章节，普通升级不会重复强制播放。
- 服务商兼容异常可以生成脱敏诊断单，并在维护者配置中继且用户明确同意后提交到维护者的私有反馈仓库；未配置中继时仍可导出诊断内容。
- 发布材料更新为七张隔离 fixture 截图，覆盖首次准备、服务商工作台、说明目录、安全恢复、活动记录、实验室和应用设置。
